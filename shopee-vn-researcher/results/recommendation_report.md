- 消费力处于增长阶段，偏好高性价比产品
- 中国供应链价格优势明显

## 四、选品策略建议

### 4.1 新手起步方案

| 阶段 | 动作 | 预算 |
|------|------|------|
| 第1周 | 上架 20-30 个 SKU（手机壳+钢化膜+数据线） | ¥500-1000 |
| 第2-3周 | 观察哪些商品有自然流量和销量 | - |
| 第4周 | 对热卖品追加库存，下架无销量 SKU | ¥500-1000 |
| 第2个月 | 扩展到充电器、支架等品类 | ¥1000-2000 |

### 4.2 采购渠道建议

**1688 采购：**
- 搜索关键词：手机壳 批发、钢化膜 钢化玻璃膜、Type-C 数据线 批发
- 筛选条件：成交额从高到低，看买家评价
- 首次小批量试单（50-100件），确认质量后再加大

**拼多多采购：**
- 部分品类（如数据线、钢化膜）拼多多的单价甚至低于 1688
- 适合少量补货，不适合大批量

### 4.3 定价策略

- **低客单价引流**：钢化膜 ₫19,900-29,900，数据线 ₫29,900-39,900
- **中等利润款**：液态硅胶壳 ₫69,900-99,900，快充头 ₫59,900-89,900
- **高利润款**：MagSafe 壳 ₫129,900-169,900，GaN 充电器 ₫199,900-259,900

### 4.4 关键提醒

- **汇率**：当前 1 VND ≈ 0.00029 CNY，汇率波动会影响利润
- **物流成本**：从中国到越南每件约 ₫10,000-20,000，需计入成本
- **平台费用**：Shopee 佣金约 5-8%，支付手续费约 2%
- **定价公式**：Shopee 售价 = 采购价 × 3（覆盖采购+物流+平台费+利润）

## 五、工具使用说明

本项目提供了完整的采集脚本，但由于平台反爬机制，需要在有权限的环境下运行：

```
shopee-vn-researcher/
├── run_auto.py           # 全自动采集脚本（需解决反爬）
├── collect_via_applescript.py  # AppleScript 方式（需开启 JS 权限）
├── collect-shopee.js     # 手动在浏览器控制台运行的 JS
├── analyzer/             # 价格对比和选品分析模块
└── collectors/           # 各平台数据采集器
```

**替代方案：**
1. 使用 Shopee 官方 API（需商家认证）
2. 使用第三方电商数据工具（如 BigC、Metric 等）
3. 手动采集热销商品数据后填入分析模板

## 六、总结

对于新手小白，最推荐的初期选品组合：

> **钢化膜（₫25,000）+ 透明手机壳（₫35,000）+ Type-C 数据线（₫35,000）**

这三个品类具备：**利润率 > 70%、标准化程度高、售后率极低、市场需求稳定** 四大优势，是跨境电商新手的最佳切入点。

初期投入控制在 ¥2000-3000 以内，测试 1 个月后根据销量数据调整品类结构，逐步扩大到充电器、耳机等高客单价产品。
